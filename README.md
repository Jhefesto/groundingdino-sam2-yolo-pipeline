# GroundingDINO-SAM2-YOLO Pipeline

Automatic annotation and refinement pipeline using Grounding DINO, SAM2, and YOLO for industrial computer vision applications.

## Features
- Video frame extraction at multiple FPS rates
- Prompt-based object localization
- Automatic segmentation with SAM2
- Dataset refinement
- YOLO training workflow
- Experimental evaluation pipeline

## Technologies
- Python
- Google Colab
- Grounding DINO
- SAM2
- YOLO

## Experimental Configuration
- FPS rates: 0.5, 1.0, 1.5
- Automatic annotation workflow
- Data-centric refinement strategy
